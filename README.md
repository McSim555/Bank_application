# Домашняя работа 10.2 в рамках проекта разработки виджета для банковских операций

## Описание: В рамках домашней работы реализован тест функций сортировки по статусу операций и сортировки по дате

## Установка:

- Клонируйте репозиторий
```git clone https://github.com/McSim555/Bank_application```
- Откройте проект bank_application в PyCharm версии >= 3.14
