# Домашняя работа 10.1 в рамках проекта разработки виджета для банковских операций

## Описание: В рамках домашней работы реализованы две функции сортировки по статусу операций и сортировки по дате

## Установка:

- Клонируйте репозиторий
```git clone https://github.com/McSim555/Bank_application```
- Откройте проект bank_application в PyCharm версии >= 3.14

## Использование:

1. Откройте ветку feature/homework_10_1
``` git branch feature/homework_10_1 ```

2. Откройте файл processing.py

3. Вызовите и выведете в консоль результат работы функции filter_by_state. 
- Пример входных данных в виде списка словарей:
```
[
{'id': 41428829, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'},
{'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'},
{'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'},
{'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}
]
```
- Пример работы функции:
